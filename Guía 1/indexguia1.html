Análisis de Correspondencia

Contenido ya estudiado en el curso Contenido nuevo y su función
Estructura base HTML: <!DOCTYPE html>, <html>, <head>, <body>, <meta charset>, <title>, <link>. <meta name="viewport"...>: Etiqueta HTML para diseño responsivo; adapta la escala y el ancho de la página a la pantalla de dispositivos móviles.
Etiquetas semánticas HTML5: <header>, <nav>, <section>, <footer>. CSS Flexbox (display: flex, justify-content, align-items): Sistema de maquetación que crea diseños flexibles en una dimensión, alineando y distribuyendo los elementos internos fácilmente (usado en la barra de navegación).
Elementos de texto, imágenes y listas: <h1> a <h6>, <p>, <a>, <ul>, <li>, <img>, <strong>. CSS Grid (display: grid, grid-template-columns, gap): Sistema de maquetación en cuadrícula de dos dimensiones, ideal para alinear las tarjetas del directorio de comercios en columnas adaptables.
Selectores CSS: Universales (*), de etiqueta, de clase (.), de ID (#), pseudo-clases de interacción (:hover) y pseudo-elementos (::before). Variables CSS (:root, var(--nombre)): Permite almacenar valores estáticos (como la paleta de colores beige, café y negro solicitada) para reutilizarlos en toda la hoja de estilos sin reescribirlos.
Fondos y Tipografía CSS: background-color, background-image, colores rgba, font-family, font-size, color, text-align. Posicionamiento CSS (position: fixed, absolute, relative, z-index): Permite superponer elementos (como el texto sobre las imágenes de las tarjetas) o fijar el menú en la parte superior al hacer scroll.
Modelo de Caja CSS: margin, padding, width, height, max-width, border, border-radius, box-shadow, box-sizing: border-box. Transiciones y Animaciones CSS (transition, animation, @keyframes, transform): Crea movimientos fluidos y efectos visuales (como el cambio de color al pasar el mouse, el pulso del logo o el zoom en imágenes).
JavaScript (DOM manipulation, timers, events): Agrega interactividad dinámica al sitio. Se utilizó para desvanecer la pantalla de carga inicial (setTimeout), rotar las imágenes del carrusel fluido (setInterval) y hacer aparecer los elementos gradualmente al bajar por la página (Intersection Observer o eventos de scroll).
